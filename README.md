# Final Project: Code Security Audit

## Overview
Complete a security audit on one of your own previous projects and write a report documenting the findings.

## Requirements
- Choose one of your past projects (desktop or web app) from another course
- Create a new GitHub repository and commit your code
- Get a peer review from at least one classmate using GitHub comments or a pull request
- Implement a GitHub Action to test for vulnerabilities
- Use at least one additional security testing tool
- Write a security audit report with a minimum of 4 issues and a maximum of 1
